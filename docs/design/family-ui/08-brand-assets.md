# 08 品牌资产：纹样、Mascot 与图标

## 1. 纹样系统

类型：云纹、水纹、山纹、折枝 / 章纹式简化边饰、萝卜 IP 线稿、低透明纸张肌理。

表现规则：

- 单色线稿优先，透明度 0.05–0.16，默认色 `--rd-pattern-line`。
- 纹样线宽细于标准分割线；视觉强度必须低于正文与边框。
- 移动端降密或隐藏。

按 Profile 的使用许可：

| Profile | 许可 |
| --- | --- |
| Brand 面 | 允许：Hero 次级背景层、band 边缘、页脚收束、空态、标题区弱装饰 |
| Workbench 面 | 默认**禁用**；仅欢迎页、空态、关于页可用极弱纹样 |
| Game 面 | 不适用（自治） |

禁止位置：长篇正文阅读区、输入框内部、按钮文字底下、表格 / 密集列表底层、二维码底层、移动端整屏平铺。

## 2. 纸感

- 纸感主要由纸阶底色 + 暖色阴影 + 克制圆角形成，不依赖纸张贴图。
- 需要真实纹理时用极低透明度肌理层，且只在 Brand 面。

## 3. Mascot「萝小白」

- 三形态（原始形象 / 可爱Q版 / 完全体）的当前素材设定与安全口径见 [素材治理](../../assets/materials.md)。
- 适用场景包括空态、404、FAQ、开发日志辅助视觉和彩蛋。
- Mascot 不自动等同于 Logo 或功能图标；下载、素材包和外部分发需单独确认授权与使用边界。

## 4. 图标风格基线

- 线性图标：1.5–2px 描边、圆角端点、24px 网格绘制；实底图标仅用于品牌位与状态徽标。
- 图标、颜色与必要文字共同表达状态，不允许仅靠颜色。
- 同一界面体系内保持一套图标风格；跨载体共享分类与识别逻辑，但可按平台调整细节。
- 本规范不指定具体图标库；选用外部图标集时应核对许可证并保持一致性。

## 5. 插画与概念图

- 概念图、生成图、三次元风格图只能标注为概念视觉 / 参考素材，不冒充实机截图或产品 UI。
- 页面优先使用真实、已审核的内容资产；无审核素材时使用明确标注的候选媒体框，不上线空泛占位图。

## 6. Logo 与临时标识

- 临时文字标识、代码内图形和占位符必须明确标注，不冒充正式 Logo。
- Logo、品牌图形和衍生资产进入正式页面前，应确认来源、版本、使用范围与授权。
- 本规范不登记任何具体产品的 Logo 完成状态或替换计划。
