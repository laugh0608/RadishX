# 08 品牌资产：纹样、Mascot 与图标

## 1. 纹样系统

类型：云纹、水纹、山纹、折枝 / 章纹式简化边饰、萝卜 IP 线稿、低透明纸张肌理。

表现规则（沿 Radish 基线）：

- 单色线稿优先，透明度 0.05–0.16，默认色 `--rd-pattern-line`。
- 纹样线宽细于标准分割线；视觉强度必须低于正文与边框。
- 移动端降密或隐藏。

按 Profile 的使用许可：

| Profile | 许可 |
| --- | --- |
| Brand 面 | 允许：Hero 次级背景层、band 边缘、页脚收束、空态、标题区弱装饰 |
| Workbench 面 | 默认**禁用**；仅欢迎页、空态、关于页可用极弱纹样 |
| Game 面 | 不适用（自治） |

全家族禁止位置：长篇正文阅读区、输入框内部、按钮文字底下、表格 / 密集列表底层、二维码底层、移动端整屏平铺。

## 2. 纸感

- 纸感主要由纸阶底色 + 暖色阴影 + 克制圆角形成，不依赖纸张贴图。
- 需要真实纹理时用极低透明度肌理层，且只在 Brand 面。

## 3. Mascot「萝小白」

- 三形态（原始形象 / 可爱Q版 / 完全体）设定与安全口径以 RadishX `docs/assets/materials.md` 为唯一真相源。
- 家族产品使用场景：空态、404、FAQ、开发日志辅助视觉、彩蛋（内部预览口径）。
- 边界：不作为任何项目 Logo 或图标；不进入下载 / 素材包 / 外部分发；可爱Q版必须符合安全口径；工作面使用前需项目层确认。

## 4. 图标风格基线

- 线性图标：1.5–2px 描边、圆角端点、24px 网格绘制；实底图标仅用于品牌位与状态徽标。
- 全家族「双通道」原则：图标 + 颜色 +（必要时）文字共同表达状态，不允许仅靠颜色（Catalyst 可访问性条款推广为家族条款）。
- 同一产品内图标只用一套风格；游戏内图标与 Wiki / 官方工具共享分类与识别系统（Catalyst 既有条款）。
- 暂不建设家族统一图标库；各项目可选用同一开源线性图标集并在差异附录登记。

## 5. 插画与概念图

- 概念图、生成图、三次元风格图只能标注为概念视觉 / 参考素材，不冒充实机截图或产品 UI。
- 页面优先使用真实项目截图、真实资产；无审核素材时用明确标注的候选媒体框，不上线空泛占位图（RadishX 先例）。

## 6. Logo 与临时标识

- 五项目当前无独立稳定 Logo；官网使用代码内文字 / CSS 临时标识，不声明为正式 Logo（RadishX 既有口径，家族沿用）。
- 未来项目 Logo 落地时，先过素材审核，再更新本章与各项目差异附录。
