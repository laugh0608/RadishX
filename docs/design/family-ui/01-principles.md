# 01 设计原则

## 家族叙事

本规范的视觉方向是：**现代界面骨架 × 纸墨印色气质**。

- 骨架来自现代清爽界面的结构、密度、组件形态与状态表达，视觉依据见 [references.md](references.md)。
- 气质来自纸色、墨色、低饱和印色、留白、少量衬线与轻纹样。
- 结果应当先是清晰、好用、可信的界面，细看再有东方温度；不是给参考图换色，也不是把传统纹样贴到通用组件上。

## 气质关键词

温润、克制、留白、纸感、印色感、低饱和、清晰、状态明确、密度有序、工程可信。

## 设计原则

1. **先结构，后装饰**：先保证信息结构、层级、可读性和交互状态，装饰只增强气质。
2. **阅读优先**：正文、表单、表格和编辑器的可读性优先于视觉表现。
3. **状态语义化**：界面应清楚回答当前状态、可信程度和下一步动作；状态色只表达状态。
4. **密度有序**：主区、辅助区和诊断区职责明确；同屏强强调色不超过两组。
5. **装饰退后一级**：纹样、纸感和边饰必须弱于正文、控件和状态。
6. **先 token 后颜色**：需要复用的视觉值先形成语义，再进入组件；避免在组件中散落无语义的硬编码值。
7. **参考后转译**：参考 UI 用于理解比例、节奏和形态，不用于复刻页面或替代独立设计判断。
8. **从起点考虑亮暗与无障碍**：颜色之外保留图标、形状或文字通道；对比度、触控目标和 `prefers-reduced-motion` 是底线。

## 避免方向

- 大面积紫蓝渐变、装饰光斑、渐变球和 bokeh 背景。
- 把深色监控大屏当作所有界面的默认气质。
- 红金国潮、厚重宫廷化、复古旧物感和满屏传统纹样。
- 荧光状态色、塑料高光和夸张渐变按钮。
- 把营销式 hero 或宽幅能力 band 生搬进高密度工作面。
- 卡片套卡片、双层大白框浮层。
- 把未实现能力画成可点击的真实执行路径。
- 用装饰替代真实内容、数据和资产。

## 通用规范与自主选择

本专题提供通用基线，不替具体产品作品牌与业务决策：

- 配色母板是候选集合，不预先分配给任何项目；主色、辅色和品牌关系由使用方决定。
- Profile 是描述界面密度与气质的参考，不是项目分类表。
- 领域组件、平台惯例、品牌资产、技术实现和发布时间均由各自上下文决定。
- 若使用本规范的状态色，则应保持 success / warning / danger / info / neutral 的语义稳定，并采用图标或文字作为第二通道。
- 若扩展 token，应优先表达新的通用语义；仅服务单一业务的值留在其本地范围。

## 参考图转译原则

参考图的重要性在于帮助设计者看到文字规则背后的视觉关系。一次有效的参考应至少回答：

1. 哪个结构或节奏值得学习；
2. 它为何适合当前内容；
3. 哪些品牌、配色、组件组合或交互路径不能照搬；
4. 转译后的方案怎样体现自身信息架构和视觉身份。

最终结果应能脱离参考图独立成立；如果只替换文字、颜色或 Logo 后仍能与原图逐区对应，说明转译不足。
