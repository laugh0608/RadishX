# 07 布局与平台适配

## 1. 布局模式库

| 模式 | 结构 | 适用 |
| --- | --- | --- |
| 工作台三栏 | 侧栏导航 + 主内容 + 右辅助栏（readiness / 证据 / 属性） | Mind、Console、Flow 检查器场景 |
| 侧栏 + 主区 | 侧栏导航 + KPI 行 + 主表格 / 卡片流 | 通用管理与列表页（ref-03/06/07） |
| 画布优先 | 顶部命令区 + 左对象库 + 中央画布 + 右检查器 + 底部消息 / 结果 | Flow Studio、Mind node designer |
| 内容流 | 顶导航 + 单列 / 双列内容流 + 可选侧栏 | Radish 公开 Web、文档阅读 |
| 展示分段 | 全宽分段 band 纵向叙事 | RadishX 官网、未来营销页 |
| 设置页 | 左设置导航 + 右表单分区 | 全家族设置界面（ref-05） |

通用规则：画布类产品中画布必须是最大且最清晰区域；侧栏 / 辅助栏各自职责稳定，不混装（Flow 先例）。

## 2. 断点与基准视口

| 名称 | 范围 | 备注 |
| --- | --- | --- |
| mobile | < 768px | 单列；基准视口 390×844 |
| tablet | 768–1079px | 可保留双栏；基准 768×1024 |
| desktop | 1080–1439px | 完整布局最低档 |
| wide | ≥ 1440px | 基准 1440×900；超宽 1728×1117 校验 |

桌面客户端设计稿基准：1920×1080；窄屏 / 竖屏稿基准：1080×1920（Mind 先例）。

## 3. 响应式规则（全家族）

- PC 与移动是一等目标；页面首版必须同时可用，不把响应式留到最后补救。
- 窄屏是**单列重排**，不是桌面缩放：按「标题与状态 → 关键指标 → 主内容 → 辅助信息」重新排序（Mind 先例）。
- 移动端：侧栏转抽屉或底部导航（底部导航 ≤ 5 项，Radish 先例）；表格降级为卡片列表或横向滚动 + 冻结首列。
- 触控目标 ≥ 44px；纹样与背景装饰在移动端降密或隐藏。
- 任何文本不得溢出、遮挡图片主体或相邻内容；长 id / 路径断行或截断。

## 4. 平台适配

每个平台分三档：必须（token 语义与状态语义）/ 建议（组件形态）/ 自治（平台惯例）。

### Web（React / Vite 等）

- 必须：直接消费 `tokens/tokens.css`（或从 tokens.json 生成），组件只用 `--rd-*`。
- 建议：按 06 章形态实现；深浅主题用 `data-rd-theme` 属性切换（Radish 双主题机制先例）。

### 桌面客户端 — Webview 壳（Tauri）

- 同 Web；窗口 chrome 遵循系统惯例，自绘时可用 4px 微倒角 + 弱对比控制钮（Radish 窗口先例）。

### 桌面客户端 — 自绘 UI（egui / Rust）

- 必须：建立 tokens.json → 样式结构体的映射表（颜色、圆角、间距一一对应），映射表入项目差异附录。
- 建议：打包 `InterVariable` + `SourceHanSansSC`；画布图元规范项目自治（Flow 既有条款继续有效）。

### 移动 / 跨平台管理端（Flutter）

- 必须：tokens.json 映射为 `ThemeData` / 自定义 `ThemeExtension`，色值不散落组件。
- 建议：密度用 comfortable 档；触控优先；底部导航 ≤ 5 项；跟随系统亮暗（预留暗色映射）。

### 游戏（Godot）

- 必须：状态色语义（success / warning / danger / info / neutral 的含义）、图标 + 颜色 + 文字多通道表达、可读性底线（字号、对比度、色盲冗余）。
- 自治：HUD、基地面板、地图的视觉气质按 Catalyst `docs/product/visual-and-ui-direction.md` 执行；其 Wiki / 官方工具回归 Workbench 面。

### 输入法候选窗（RadishLex 平台薄壳）

- 必须：极简、安静、不与宿主应用抢视觉；候选高亮用 `--rd-action-soft` 语义（各平台色值就近映射）；字号可调；跟随系统亮暗。
- 自治：各平台（IMK / Fcitx5 / TSF / Android IME）的窗口形态遵循平台惯例；管理端（Flutter）不适用本节，按 Workbench 面执行。

## 5. 视觉验收基线（全家族最小集）

- 至少检查一个桌面视口和一个移动 / 窄屏视口。
- 状态色只用于状态语义；同屏强色 ≤ 2 组。
- 无文本溢出、遮挡、错位；中英切换与长名称不引起布局跳动。
- 禁用与阻断有原因说明；未实现能力未被画成可执行入口。
- `prefers-reduced-motion` 生效。
