# 视觉规范

本文定义 RadishX 官网的视觉方向和素材使用原则。

## 总体气质

RadishX 官网应偏创意品牌、游戏感和视觉冲击，参考 Apple 官网的页面节奏：

- 大幅真实视觉。
- 少量高密度文案。
- 清晰分区和留白。
- 每屏只强调一个核心信息。
- 入口明确，交互克制。

## Radish 视觉继承

本官网参考 Radish 项目的视觉规范，但不直接复刻 WebOS 或 Console。

可继承的关键词：

- 温润
- 克制
- 留白
- 纸感
- 低饱和
- 轻纹样
- 层次分明

需要避免：

- 过度红金化。
- 过度国潮海报化。
- 过多装饰压过内容。
- 把官网做成管理后台。
- 把官网做成 WebOS 桌面复刻。

## 页面节奏

首页建议采用强视觉分段：

1. 首屏：RadishX 品牌主视觉和一句核心定位。
2. 项目矩阵：四个项目用强视觉入口呈现。
3. 生态关系：说明四个项目之间的定位。
4. Mascot 入口：虚拟形象作为品牌记忆点。
5. About / GitHub：收束到联系和仓库入口。

项目详情页建议结构：

1. 项目名和一句核心定位。
2. 大图或截图。
3. 关键能力。
4. 当前状态。
5. GitHub 与未来独立域名入口。

Mascot 页建议结构：

1. 三种形态总览：原始萝卜、儿童萝卜、成熟少女萝卜。
2. 每个形态的设定说明和主图。
3. 表情包 / 服装 / 节日素材 Gallery。
4. 使用说明和版权提示。

## 色彩方向

主色不应只有单一萝卜绿。建议采用多层色彩：

- 背景：暖白、纸色、浅灰。
- 品牌点缀：萝卜绿。
- 辅助强调：深墨色、浅金、低饱和粉、低饱和蓝灰。
- 状态或活动：小面积使用更强颜色。

同一屏强色不超过两组。

## 字体和排版

- 中文正文优先使用系统无衬线。
- 大标题可以尝试更有品牌感的字体，但必须保证可读性。
- 英文品牌名使用现代无衬线。
- 不用 viewport width 直接控制字体大小。
- 移动端标题应有独立字号，不靠桌面字号硬缩放。

## 图片使用

正式写入页面前，必须先确认具体选图。

推荐用途：

- 首页主视觉：优先使用成熟少女或儿童萝卜设定图中的长期稳定素材。
- Mascot 页：完整展示三种形态和设定图。
- 项目详情页：优先使用对应项目真实截图、Logo 或关键视觉。
- 节日图：只用于活动 Banner 或节日彩蛋，不作为长期默认主视觉。

图片实现要求：

- 设置 `alt` 文案。
- 设置稳定尺寸、比例或容器约束。
- 移动端裁切需要人工检查主体是否完整。
- 不使用过暗、过糊、主体被裁掉的图片作为首屏核心视觉。

## 动效原则

- 动效应轻量、克制、服务滚动节奏。
- 可以使用淡入、视差、轻微位移和图片层次切换。
- 不使用影响阅读的持续抖动或复杂背景动画。
- 移动端减少动效强度，并尊重 `prefers-reduced-motion`。
