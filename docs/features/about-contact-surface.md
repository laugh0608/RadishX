## 历史目标与实现边界（2026-06 / 07）

以下保留 2026-06 / 07 的目标、设计与实现记录；历史数量不代表当前范围，现行入口数量见上方最新批次，公开页面继续避免内部审核语言。

## 目标

把 `/about` 打磨成 RadishX 的稳定联系、社交媒体、仓库入口和域名边界页面，让访问者能快速找到联系方式、公众号二维码、GitHub 仓库和已确认的公开入口。

## 背景

About 页已完成首版实现，并接入微信公众号二维码 Web 图。首轮已在不新增外部服务、不修改域名策略、不引入未审核图片的前提下，整理页面节奏、联系信息层级、仓库入口和域名边界。

2026-06-17 二轮扫读优化继续保持同一边界，只针对信息密度、标题层级、重复外链上下文和移动端可读性做小范围调整。

## 范围

- `/about` 页面整体信息层级。
- 联系方式：QQ、Email、GitHub 主页、个人主页。
- 微信公众号二维码和说明。
- 14 个公开 GitHub 仓库入口（官网、十二个项目与 Axiom Checker）。
- `radishx.com`、`www.radishx.com`、`hub.radishx.com` 与 `ink.radishx.com` 四项域名边界。
- About 页相关结构化数据和样式。

## 不做

- 不新增未确认社交媒体或第三方服务。
- 不把微信公众号二维码移到首页首屏。
- 不修改域名策略或 Vercel 配置。
- 不新增表单、后端 API、订阅系统或数据库。
- 不引入未审核图片。
- 不为未部署项目展示计划域名、禁用访问按钮或“即将上线”暗示。

## 设计要求

- 桌面端应形成清晰的联系方式主列、二维码视觉点和仓库 / 域名分区。
- 移动端优先单列可读，长邮箱、URL、仓库名和域名不能溢出。
- 二维码区域要清楚，但不能压过联系方式和仓库入口。
- 外链入口需要可点击区域足够大，状态和目的明确。
- 页面文案保持克制，不写成组织宣传长文。
