# About 联系区

状态：首轮精细化已完成
最后更新：2026-06-14

## 目标

把 `/about` 打磨成 RadishX 的稳定联系、社交媒体、仓库入口和域名边界页面，让访问者能快速找到联系方式、公众号二维码、GitHub 仓库和未来项目入口状态。

## 背景

About 页已完成首版实现，并接入微信公众号二维码 Web 图。本轮已在不新增外部服务、不修改域名策略、不引入未审核图片的前提下，整理页面节奏、联系信息层级、仓库入口和域名边界，让桌面和 390px 移动端都更容易扫读。

## 范围

- `/about` 页面整体信息层级。
- 联系方式：QQ、Email、GitHub 主页、个人主页。
- 微信公众号二维码和说明。
- 五个 GitHub 仓库入口。
- `radishx.com`、`www.radishx.com` 和四个未来项目域名边界。
- About 页相关结构化数据和样式。

## 不做

- 不新增未确认社交媒体或第三方服务。
- 不把微信公众号二维码移到首页首屏。
- 不修改域名策略或 Vercel 配置。
- 不新增表单、后端 API、订阅系统或数据库。
- 不引入未审核图片。

## 设计要求

- 桌面端应形成清晰的联系方式主列、二维码视觉点和仓库 / 域名分区。
- 移动端优先单列可读，长邮箱、URL、仓库名和域名不能溢出。
- 二维码区域要清楚，但不能压过联系方式和仓库入口。
- 外链入口需要可点击区域足够大，状态和目的明确。
- 页面文案保持克制，不写成组织宣传长文。

## 开发任务

1. 已梳理 `/about` 当前 section 顺序和信息密度，保留“联系方式 / 微信公众号 / GitHub 仓库入口 / 域名边界”的页面节奏。
2. 已优化联系方式展示：每个入口补充用途说明和动作标签，长邮箱、个人主页和 GitHub 账号允许换行。
3. 已优化微信公众号二维码区域：二维码使用已审核 Web 图，说明从素材路径改为名称、用途、素材状态和边界。
4. 已优化 GitHub 仓库入口：每个仓库展示 `owner/repo`、项目状态、角色和对应公开 surface。
5. 已优化域名边界区：补充 `www.radishx.com` 兼容入口，并继续明确四个未来项目域名不是当前官网 Vercel rewrite。
6. 已更新对应文档、开发日志和必要验证记录。

## 本轮实现记录

- `src/data/contacts.ts`：扩展联系方式、微信公众号说明、GitHub 仓库入口和域名 surface 数据。
- `src/pages/AboutPage.tsx`：重排 About 联系区结构，增加联系动作、二维码事实项、仓库角色说明和 6 个域名边界卡片。
- `src/styles/global.css`：补充 About 专用布局和响应式规则，约束长文本、按钮、二维码说明、仓库卡片和域名卡片不溢出。
- `src/app/routes.ts`：将 About 页面 metadata 描述中的微信公众号口径从占位改为二维码。

## 验证

## 完成标准

- 联系方式、二维码、仓库入口和域名边界都能在一页中自然扫读。
- 长文本和按钮不溢出、不重叠。
- 文档和开发日志同步记录结果。
