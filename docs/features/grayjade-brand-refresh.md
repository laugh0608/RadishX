# 灰玉品牌视觉与 v1 设计源

## 目标

在不改动现有 React 页面的前提下，把 RadishX 的下一版视觉方向从胭脂主识别调整为「纸色为底、灰玉识别、墨蓝操作、胭脂点睛」，并在新的 `docs/design/sources/radishx-site-v1.pen` 中完成具有明确视觉叙事的首页桌面与移动设计供评审。

## 背景

现有 `radishx-site-v0.pen` 与 React v1.2 craft 基线使用胭脂 `#b24057` 作为品牌识别。2026-07-31 决定将 family-ui 默认品牌参考色切换为 1 元系灰玉，同时保留墨蓝操作色和其他纸币色系作为可选 accent。

## 本轮范围

- 保留 `radishx-site-v0.pen`，不覆盖历史设计源。
- 新建 `radishx-site-v1.pen`。
- v1 首轮只保留并设计 `Home Desktop v1 - Grayjade Study` 一张页面。
- 桌面方向阶段性认可后，新增一张 390px `Home Mobile v1 - Grayjade Study`，完整覆盖 Header、Hero 项目舞台、五项目内容区和 Mascot 舞台。
- 亮色品牌主色使用深灰玉 `#5d6c57`，柔底使用灰玉浅阶，页面底继续使用纸色。
- 墨蓝继续承担操作、信息和工程可信感；胭脂降为小面积印章式点缀。
- 使用 `docs/design/family-ui/reference-ui/` 中的参考 UI 理解留白、层级和视觉节奏，但不复刻具体页面。
- 二轮视觉重构清理标题下的解释型副标题；项目区不再复用横向 band 模板，Mascot 区不再使用图片卡片。
- 新生成一张透明底萝小白完全体候选立绘，只用于 v1 Pencil 评审，不进入 React 或 `public/`。

## 当前结果

- 已新建 `docs/design/sources/radishx-site-v1.pen`，旧 `v0` 文件未修改。
- v1 当前包含 `Home Desktop v1 - Grayjade Study` 1440px 桌面画板与 `Home Mobile v1 - Grayjade Study` 390px 移动画板。
- 灰玉进入品牌字、主 CTA、Hero 柔化背景、项目矢量图形和 Mascot 深色舞台；纸色仍是页面主背景，项目色保持小面积识别。
- Hero 与分区标题均删除解释型副标题，只保留标题、必要的状态元数据和操作入口。
- 五项目改为不对称生态图谱：Radish 使用社区轨道，RadishCatalyst 使用全幅工业场景，RadishFlow 使用流程蓝图，RadishMind 使用节点星图，RadishLex 使用中文输入路径。
- Mascot 区改为无图片框的深灰玉立绘舞台，透明角色、背景大字、轨道线和轻量 CTA 共同建立品牌记忆点。
- 三轮校正移除了 Radish 社区轨道和 Mascot 舞台中用椭圆临时拼接的伪品牌符号；Radish 改用已审核角色素材表达社区成员，Mascot 舞台保留干净留白，不再虚构 Logo。
- 四轮校正将 Hero 右侧的“中心角色 + 五项目环卡”改为单项目视觉舞台：Radish 首帧直接呈现社区动态、内容状态和成员角色，五个项目收敛为底部切换索引，不再用抽象轨道暗示不存在的中心关系。
- 移动首版按独立单列节奏重排：导航收敛为品牌与菜单，Hero 按标题、操作、项目舞台顺序展开，五个项目分别保留社区轨道、工业场景、流程蓝图、节点网络和中文输入视觉，Mascot 以深灰玉全幅舞台收束。
- Pencil 布局检查返回 `No layout problems.`；已完成整页、Hero 项目舞台、项目图谱和 Mascot 舞台预览，并在四轮评审中复核结构与符号清理结果。
- React 与 `src/styles/family-ui-tokens.css` 保持 v26.7.2 实现基线，未提前换色。

## 不做

- 本轮不修改 `src/` 中的 React 页面与运行时 token。
- 不删除或改写 `radishx-site-v0.pen`。
- 不一次性完成暗色和其余页面。
- 不把本轮生成的候选立绘复制进 `public/` 或 React 页面，不将其视为已经确认的正式品牌资产。
- 不安装新字体、依赖或第三方运行时。
- 不把参考 UI 截图放进设计页。

## 设计要求

- 画面应明显减少胭脂主导感，但不能变成大面积单一绿色。
- 首页首屏在 1440px 桌面画板中清楚表达品牌、项目矩阵定位和主入口。
- 灰玉主要承担品牌识别、主 CTA、焦点与柔化氛围；纸色继续承担大面积背景。
- 亮色实底按钮使用深灰玉 + 暖白文字，普通文本对比度不低于 WCAG AA。
- 项目色只保留为少量识别点，同屏强色不超过两组。
- 参考图的作用是帮助判断空间比例、视觉重量、圆角和阴影，不允许照搬结构、组件组合或文案。
- 分区标题默认独立成立，不在标题下追加解释当前布局、实现方式或页面职责的副标题。
- 项目矩阵必须让不同项目拥有不同的视觉语法，不能只在同一张图文卡片模板中替换标题和图片。
- Hero 项目入口优先让一个项目的真实内容形态成为主舞台，其余项目作为索引切换；不以中心辐射图、组织关系图或同构标签卡代替项目内容。
- 移动端使用独立重排，不按比例压缩桌面画板；装饰密度进一步降低，项目索引允许横向扫读，所有文字、按钮和媒体保持单列可用。
- Mascot 主视觉优先使用透明立绘与场景化排版，不把角色缩进普通白底图片框。
- 没有经过确认的正式品牌资产时，不用临时几何图形拼接成类似 Logo 的符号；应使用真实素材、字体与版式结构或留白建立视觉焦点。
