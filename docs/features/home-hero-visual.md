# 首页首屏与主视觉

状态：R2.2 首页 React 重构完成，桌面与移动复核通过
最后更新：2026-10-17

## 目标

把首页从“等权项目卡片目录”改为编辑式项目展陈：首屏用品牌字形、品牌主张和四项精选建立气质，正文用分层目录完整保留十二个项目，并以萝小白舞台收束。

## 背景

历史首页使用单项目内容舞台与五项目 tab，后续扩到十二项后出现两个问题：底部索引只能看到部分项目；七个没有代表图的项目退化为单字母占位卡。R2.1 已确认“精选展示、完整目录、跨页统一”的方向，但没有落进 React。本轮按所有者确认实施 R2.2，精选为 Radish、RadishInk、RadishFlow、RadishLex，范围仅首页。

## 范围

- `/` 首页 Hero、四项精选舞台、十二项项目目录、萝小白舞台与紧凑页脚。
- 首页锚点从 `#projects` 迁移到 `#collection`，保留 `#projects` 兼容锚点。
- 桌面 1440×900 与移动 390×844 的独立编排。
- 首页 metadata、Open Graph 图继续沿用；本轮不替换分享预览图。

## 不做

- 不重构项目详情页、About、Mascot 页面。
- 不新增外部图片、字体、依赖或第三方服务。
- 不把代码内排版 / 示意图声明为真实产品截图或正式 Logo。
- 不把未部署项目包装成可点击体验入口。
- 不复刻 Radish WebOS 或 Console 管理后台结构。

## 当前实现

- Hero 使用 `RadishX` 品牌字形、“把好奇心，做成作品。”、四项精选切换与“浏览全部项目”入口。
- 精选使用原生 `tablist` / `tab` / `tabpanel` 语义，支持点击、方向键、`Home` 与 `End` 键切换；不做自动轮播。
- 精选视觉：Radish 使用既有角色图，Ink / Flow / Lex 使用代码内排版与流程视觉；不新增外部素材。
- 项目目录使用 12 列编辑式网格：2 个大型展面、2 个强视觉展面、4 个中型展面和 4 个紧凑条目；十二项全部可见，不再依赖横向滚动索引。
- 目录按 Community & Creation、Tools & Workflow、Games & Worlds、Explorations & Systems 分组，Flow 按当前“开发中”状态展示，不使用历史项目标签。
- 顶部 `Projects` 导航在首页和项目详情页保持 active；点击跳转 `/#collection`，旧 `#projects` 仍可作为兼容锚点。
- 首页公开文案移除 `Temporary mark`、`Reviewed asset`、`Asset source`、`Usage boundary` 等内部评审语言。
- 移动 Header 使用既有 44px 菜单按钮；首页移动端独立编排，不依赖 hover。
- 紧凑页脚只保留“全部项目 / 萝小白 / About / GitHub”，避免重复罗列十二个项目名。

## 设计要求

- 首屏先说明 `RadishX`，再用精选项目承载内容；项目目录负责完整索引，不与首屏争抢主次。
- 项目视觉优先用排版、领域符号和已审核图片表达，不用同一套卡片模板填充所有项目。
- 桌面保持大留白与强视觉；390px 移动端优先连续阅读，标题与按钮不压缩。
- 精选切换保留可见焦点与键盘操作；`prefers-reduced-motion` 下关闭入场动画和位移动效。
- 文字对比度优先使用主文字 / 次文字 token；微标签不再依赖低对比度 muted 小字。

## 完成标准

- 桌面和 390px 移动端能稳定呈现四项精选与十二项完整目录。
- 首页不出现未部署项目的访问链接、计划域名或内部评审语言。
- 已审核图片正常加载，代码内视觉不被描述为真实产品截图。
- 目标文档、当前规划和开发日志已同步。
