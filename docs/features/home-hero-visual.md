# 首页首屏与主视觉

状态：首屏 v1 视觉锚点已接入，等待长期主视觉最终选图
最后更新：2026-06-14

## 目标

让首页首屏稳定表达 RadishX 是 Radish 系列项目矩阵，同时为后续正式主视觉、Mascot 站姿图和项目媒体图替换保留清晰入口。

## 背景

首页已采用 `Radish Orbit` 方向，用项目星图、四道入口和 Mascot 叙事结构承载第一版主视觉。当前策略是不把未审核图片提前放进正式页面，而是用已确认素材和结构化状态槽表达素材接入边界。

本轮设计确认：首屏 v1 继续以项目星图表达矩阵关系，同时把已审核的可爱Q版安全设定图作为中心视觉锚点；这不是长期最终主视觉确认，也不触发 Open Graph 图替换。

## 范围

- `/` 首页首屏文案、CTA、项目矩阵和 Radish Orbit。
- 首页 Mascot 辅助视觉与首屏中心视觉锚点。
- Hero 主视觉、Mascot 三形态和项目媒体三类素材状态槽。
- 首页相关 metadata 和 Open Graph 图的后续替换判断。

## 不做

- 不在未审核前接入新的首页大图。
- 不把四个项目详情页素材直接扩散到首页主视觉。
- 不把 Open Graph 图频繁替换为尚未稳定的临时视觉。
- 不复刻 Radish WebOS 或 Console 管理后台结构。

## 当前实现

- 首页首屏继续使用 Radish Orbit 作为 v1 主结构，四个项目入口围绕中心视觉锚点展开。
- 已接入 `public/images/mascot/radish-child-safe-design-sheet-v1-web.jpg` 作为首屏中心视觉锚点和后续 Mascot 入口的辅助视觉。
- 素材状态槽已展示 Hero 主视觉、Mascot 三形态和项目媒体的当前状态、边界和后续需求。
- 当前 Open Graph 图使用已确认完全体设定图生成，适合作为首版分享预览；本轮不替换。

## 设计要求

- 首屏必须先说明 `RadishX` 和项目矩阵关系，再承载装饰和角色视觉。
- 桌面端保持强视觉和留白；390px 移动端优先连续阅读，不压缩标题和按钮。
- 状态槽只表达素材治理信息，不做成密集说明页。
- 任何新增图片必须能在移动端完整展示主体，不能裁掉角色或关键 UI。

## 开发任务

- 继续等待首页长期主视觉选图确认；确认后再生成 Web 优化版本并进入 `public/images/`。
- 如果主视觉替换改变页面首屏气质，同步检查 `docs/design/visual-guidelines.md`。
- 评估是否更新 `public/images/social/radishx-og-image.png`。
- 保持首页项目 band 与四个项目详情页素材口径一致。
- 后续如果改用站姿图，必须先在 `docs/assets/materials.md` 中把对应站姿素材状态从“待确认”更新为可正式使用。

## 验证

- `npm run build`
- 桌面视口检查 `/`，建议 `1440x900`。
- 移动视口检查 `/`，建议 `390x844`。
- 检查首屏标题、CTA、项目节点、素材状态槽无横向溢出。
- 检查新增图片实际加载、`alt` 合理、主体不被裁切。

## 完成标准

- 首页首屏能在桌面和 390px 移动端稳定表达项目矩阵。
- 已确认图片进入 `public/images/`，未审核图片不进入正式页面。
- Open Graph 是否替换有明确结论。
- 目标状态、规划和开发日志已更新。

## 后续事项

- 评估 Mascot 站姿图是否适合替换当前辅助视觉。
- 四个项目有稳定 Logo 或截图后，再评估首页项目 band 视觉升级。
