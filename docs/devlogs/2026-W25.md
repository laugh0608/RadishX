## 关键决策

- 可爱Q版高分辨率站姿图作为当前首页中心视觉锚点。
- 虚拟形象完全体站姿图作为 Mascot 页当前主视觉。
- 本轮不替换 `public/images/social/radishx-og-image.png`；现有横图包含 RadishX 标题、项目矩阵信息和 Mascot 视觉，比直接使用方形站姿图更适合作为当前社交预览。
- 站姿图只用于公开展示和品牌识别，不提供下载入口，也不声明可自由复用。
- RadishMind 当前继续使用代码内视觉，不把外部参考截图、未审核图片或概念化 Console 包装成正式产品 UI。
- 四个项目临时标识只作为官网信息识别，不声明为正式 Logo；后续如有独立稳定 Logo，再按素材审核流程替换。
- 二轮项目素材复核后，不把 Godot 默认图标、客户端默认头像、外部产品参考截图、概念 HUD 图、历史 UI 或 archived 项目截图上调为正式 Logo、真实截图或公开视频素材。
- 可爱Q版表情和贴纸当前只作为整图预览，不拆分单张，不提供下载入口；节日图继续只作为活动 Banner、彩蛋或运营候选。
- Mascot 单张拆分会形成可独立传播的衍生素材；未建立拆分清单、命名规则、授权边界和文件包边界前，不生成单张文件、缩略图或下载入口。
- Seasonal 图均带有固定年份、节日祝福或活动场景，当前只保留为短期活动候选；未确认活动窗口、页面位置、文案、授权和撤下策略前，不进入长期 Gallery、默认主视觉或 `public/images/`。
- 本轮可访问性整理只修语义和链接名称，不改变视觉方向、不接入新素材、不触发发布流程。
