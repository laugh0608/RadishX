## 关键决策

- 合成方向：现代工作台骨架 × 纸墨印色气质；结构取自参考图，色彩取自 Radish 人民币纸币色系母板。
- 统一 token 前缀 `--rd-*`；各项目现有前缀降级为 L2 别名，逐步替换，不要求一次性改代码。
- 品牌色与操作色拆分（`brand` 胭脂红 ≠ `action` 墨蓝），化解 Console「主色蓝、品牌红」冲突。
- 状态色收敛：danger 与品牌红拆分（`#c3564d`），warning 统一回印色暖赭（废弃 AntD 黄 `#faad14`）。
- 兄弟项目未来撤专题时保留「差异附录」承载领域组件（画布图元、HUD、候选窗等），不全删。
- 参考图按外部截图口径登记：仅内部风格参考，不进入 `public/`、不对外分发。
- RadishLex 官网定位由项目所有者拍板：未来域名 `lex.radishx.com`、状态 `Source Available`、accent 用灰玉 `#78a496`（与 Radish 玉青区分，避免撞色）。
- 官网 token 迁移遵循迁移说明书自定原则「等价替换 + 登记，视觉收敛另开批次」。
- family-ui 版本号采用家族日历版本号 `vYY.M.RELEASE`（首版 `v26.7.1` = 2026 年 7 月第 1 版），对齐 Radish（Docs 发版流程）与 RadishFlow（tag `v26.5.1`）的实际格式；曾误用纯日期 `2026-07-11`，已修正。
- 官网硬编码颜色用 `color-mix(in srgb, var(--rx-*) N%, transparent)` 收敛（与 rgba 在 premultiplied alpha 下数学等价），实现零视觉变化的 token 化。
- 暗色是主题选项而非气质改变：Brand 面纸墨印色在暗色下转译为「墨底 + 印色提亮一档 + 阴影转黑 + 纹样减弱」，不做简单反色；`bg-ink` 深底强调块在暗色下靠 `text-on-ink` 前景与 `brand-primary` 提亮保持可读与醒目。
