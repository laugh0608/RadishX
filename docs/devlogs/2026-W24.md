## 关键决策

- `x.radishx.com` 不直接作为 Radish 本体入口，保留给实验、短链或统一跳转页。
- 四个项目未来域名不是当前官网的 Vercel 路由。
- 首页风格偏创意品牌、游戏感和视觉冲击，但保留 Radish 的温润、克制、纸感和低饱和视觉 DNA。
- 第一版项目详情页优先开放 GitHub 链接，未稳定上线的 Demo、下载页或独立项目站点不强行展示。
- “萝小白”可爱Q版官网素材必须使用完整外装、非性感化、无内衣展示、无身体拆解的安全版本。
- 官网代码、文档和原创素材使用 source-available 口径，第三方内容遵循其各自许可证。
- 官网设计采用 Pencil-first 流程：先在 `.pen` 中确认首页、项目模板、Mascot 和 About，再进入 React 实现。
- RadishX 视觉基线吸收 Radish 淡雅新中式、纸感、印色感和低饱和配色，并参考 MiMo Code 的现代东方页面节奏，但不复制其页面、图标、配色或文案。
- 早期首页低保真稿被判定过于贴近 MiMo Code 的结构，已从 Pencil 源文件删除；后续只以 v1 的 Radish Orbit 方向继续推进，只保留参考页的纸感、轻纹样、柔和浮层和滚动节奏。
- 四个项目详情页第一版不强求真实截图或视频，先保证定位、状态、GitHub、未来域名和项目关系清楚。
- 官网站点图标和项目临时 Logo 可使用萝小白原始形象；未来项目有独立 Logo 后再替换。
- 第一版 React 路由不引入 `react-router-dom`，先用轻量路由表和 History API 保持静态官网依赖收敛。
- 第一版公开页面不使用未审核候选大图；Mascot 和 About 中与未确认素材相关的位置先展示审核状态或图形化占位。
