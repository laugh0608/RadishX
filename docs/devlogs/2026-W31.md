## 关键决策

- family-ui 是通用参考真相源，不是跨项目管理台；具体项目可自行决定品牌色、采用范围、技术映射和升级节奏。
- UI 参考图对理解空间比例、密度和视觉效果非常重要，但只能用于观察、拆解、提炼和转译，不允许照抄或作为产品素材。
- v1 灰玉方案不做大面积单一绿色：背景仍使用纸阶，灰玉只承担身份与重点动作，墨蓝继续承担操作和信息语义。
- 暗色下亮灰玉实底必须配深墨 `text-on-brand`，不沿用白字。
- 项目矩阵不能靠同一套图文卡片重复五次；领域差异应直接转译成视觉结构差异。
- 首页分区标题不承担实现说明，解释当前布局或页面职责的句子应删除或移入真正的正文。
- 角色主视觉采用透明立绘舞台，不再使用白底图片框；生成式候选仍需经过正式页面素材审核。
