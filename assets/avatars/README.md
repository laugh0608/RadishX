# RadishX Avatar Assets

这里存放 RadishX 官网候选虚拟形象素材。文件已经从原始哈希文件名整理为语义化名称，方便后续在 Vite / React 项目中引用。

当前只做素材归档；正式用于页面前仍需要审核具体选图。

## 分类

- `origin/`：萝小白原始形象。
- `child/`：萝小白可爱Q版安全候选素材。
- `mature/`：萝小白虚拟形象完全体。
- `seasonal/`：节日、运营和活动素材。

## 使用建议

- 首页长期主视觉：优先从可爱Q版或虚拟形象完全体的设定图和站姿图中选择。
- 虚拟形象页：使用 `origin/`、`child/`、`mature/` 三组素材展示形态演进；可爱Q版优先使用 `radish-child-safe-design-sheet-v1.png`。
- 活动 Banner：使用 `seasonal/`，不要作为官网长期默认视觉。
- 表情包展示：可以在虚拟形象页作为可选 Gallery 展示，后续再决定是否拆分单张贴纸。
