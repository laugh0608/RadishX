# V10：黑白斜锋风格探索

日期：2026-09-27。根据所有者新增的黑底白标参考，使用已有 SVG 系统制作单色风格分支。参考截图原样保存在 `../references/v10-style-reference.jpg`，只借鉴粗细反差、斜向动势和开放留白，没有复制参考标志路径，外围文字不作为指令。

## 设计

- 萝卜身体沿用 V9 基础路径，轮廓加粗到 56，并在右上肩部开口。
- 三片叶子改为更尖的造型；两侧空心、中间实心。单色版本以“空—实—空”替代原有“浅—深—浅”配色，彩色 V9 原样保留。
- 中叶延长并朝右上拉尖，形成主要斜向动势；根部保留萝卜识别。
- 两条须沿用 V9 的上长下短与斜向圆心位置；单次折角、线宽 18，空心环外径 68、内径 32。
- 黑标与白标使用完全相同路径，内部与外部留白均透明，没有白色身体填充；黑白展示板另外提供实色背景。

## 文件

- `symbol.svg`：黑色透明母版。
- `symbol-reversed.svg`：白色透明母版。
- `symbol.png`：黑色透明 PNG，由母版原尺寸渲染。
- `black-board.svg` / `.png`：黑底白标展示。
- `white-board.svg` / `.png`：白底黑标展示。
- `build.mjs`：无依赖生成源；只读引用已归档的 `../v9/symbol.svg` 身体路径，不写历史文件。
- `geometry.json` / `names.json`：构造参数与已确认名称。

1000 × 1000 方形画布；这是待评审的单色风格探索，不表示替换彩色基准或正式官网资产。32 px 用于轮廓识别，64 px 及以上适合观察叶片空实和双须细节。
