# V8：几何曲线母版

日期：2026-09-27。所有者已授权在 V7 基础上采用 SVG 几何重绘；本稿使用代码定义矢量路径，无 imagegen 调用、位图自动描摹或第三方图形素材。保留浅—深—浅三叶、双电路须、双空心圆与近方形斜向构图。

## 文件

- `symbol.svg`：可编辑主母版，1000 × 1000 画布，外部透明，根部白色。
- `symbol.png`：由该 SVG 经本机 Chrome 原尺寸渲染的透明 PNG，未对历史 PNG 做转换。
- `construction.svg`：实际生成参数对应的圆弧、圆心、轴线和尾部贝塞尔控制柄。
- `junction-detail.svg`：同一矢量内容的叶根放大视窗。
- `build.mjs`：无依赖生成源，运行 `node assets/brand/radish-intelligence/v8/build.mjs` 重建三个 SVG 和 `geometry.json`；PNG 需另行通过浏览器渲染。
- `geometry.json`：参数和切线连续性数值检查。
- `geometry-check.json`：对 PNG 的只读像素外接尺寸测量。
- `names.json`：沿用已确认品牌命名。

## 构造与修正

统一坐标系为 1000 单位，整体平移 (25, 10) 做居中调整，不做非等比缩放。

| 部件 | 规则 |
| --- | --- |
| 身体 | 圆心 (430, 540)，半径 295；保留 305° 真圆弧，其余连接尾部。 |
| 尾部 | 四段三次贝塞尔；与身体圆弧及相邻段的切线方向一致。根尖用短曲线收口。 |
| 叶冠 | 三片均使用半圆头部及相切贝塞尔肩部，半径 61 / 66 / 55，旋转 8° / 43° / 78°；有色内部采用相同构造规则。 |
| 叶根 | 所有叶片的深色外形先画、彩色内部后画，再由连续闭合的身体圆弧统一分界，消除开路径圆头和重复描边。叶间凹口保留辨识。 |
| 主轮廓 | 32 单位，深绿 `#203c35`；浅叶 `#91bd5e`，中叶 `#436e60`。 |
| 双须 | 22 单位线宽，相同的水平—45°—水平走线；相切圆角半径 8，垂直间距 91。起点限制在身体轮廓内。 |
| 空心触点 | 同心圆环；外径 76、内径 32，两个尺寸完全一致。 |

主轮廓与尾部执行 G1（切线方向一致）检查，不声明整幅图形达到 G2（曲率连续），也不宣称三叶拼接处全部平滑。叶根与身体的白色分界直接采用同一圆弧，不存在此前的独立描边端帽。

构造图展示的是生成母版实际使用的几何，不是事后套圈。Apple 的历史讨论来源仍为 [Rob Janoff 访谈](https://creativebits.org/interview/interview_rob_janoff_designer_apple_logo/)：原稿主要手绘，后续经过更几何化的调整；本稿没有套用 Apple 的轮廓或黄金比例假设。

## 使用状态

这是待所有者评审的矢量候选，未替换官网、favicon 或 GitHub 组织头像。深墨背景可用于对比，但此版深绿轮廓不作为暗底专用反白版。32 px 只用于极小图形识别检查，触点细节以 64 px 及以上更清楚。
