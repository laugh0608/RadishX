# 萝卜智能：英文命名与 Logo 第一版提案

日期：2026-09-26。用途：公司 / 工作室品牌讨论。尚未作为 RadishX 正式品牌接入页面。

## 推荐命名

- 中文暂定全名：萝卜智能科技集团有限公司。
- 英文全名提案：Radish Intelligent Technology Group Co., Ltd.
- 对外品牌：Radish Intelligence。
- 品牌简称：RI；全名首字母可写 RITG，但不建议作为主要对外标识。
- GitHub 组织用户名候选：RadishIntelligence。
- 工作室方向备选：Radish Studio，简称 RS，GitHub 候选 RadishStudio。
- 通用科技方向备选：Radish Technologies，简称 RT，GitHub 候选 RadishTechnologies。

用户名可注册性未确认；本次未创建组织、注册域名或办理名称登记。

## 设计

用两片芽叶与圆润字母 R 建立统一符号，表达 Radish 的名称记忆与持续生长。灰玉、暖白、墨色延续家族视觉；品牌主标与萝小白吉祥物可承担不同用途。

建议规范色：深灰玉 #42695D、辅助灰玉 #78A496、暖白 #FDFBF7、墨色 #1C2421。生成式提案中的色值标签与实际像素可能有偏差，最终矢量定稿应按此文字色值校准。
