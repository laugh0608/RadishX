# V9：斜向双须轻线版

日期：2026-09-27。本轮在 V8 可编辑 SVG 上局部修改，仅调整双须与空心触点。三叶配色、身体、尾部和叶根分界沿用 V8。

## 调整

| 项目 | V8 | V9 |
| --- | --- | --- |
| 电路线宽 | 22 | 16，减细约 27% |
| 每路转折 | 水平—斜线—水平，两次 | 水平—斜线，一次 |
| 转折圆角半径 | 8 | 12 |
| 圆环外径 / 内径 | 76 / 32 | 64 / 32，孔径不缩小 |
| 上方圆心 | (282, 594) | (338, 594) |
| 下方圆心 | (282, 685) | (270, 662) |
| 两孔轴线 | 竖直 | 从下孔至上孔为 −45°，朝向右上叶冠 |
| 两环边缘净空 | 15 | 约 32.17 |

所有坐标为 1000 单位原始坐标；整图沿用 (25, 10) 平移。上路比下路更长；取消末端水平平台，斜线直接接入圆环。圆环白色内部盖住接入线，保持空心。起点继续限制在身体内部，避免伸出外轮廓。
