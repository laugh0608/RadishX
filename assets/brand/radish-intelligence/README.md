## 第十版方向

参考新附件的黑白反差、粗轮廓与斜向动势，采用开放身体轮廓、尖长实心中叶与两侧空心叶，以空—实—空表达单色层次；两条须继续沿斜向排列。保存黑标 / 白标透明 SVG 与黑白展示板。身体基础路径只读继承 V9，当前为独立风格分支，彩色稿完整保留。

## 第九版方向

根据所有者反馈，只调整内部双须。上路加长、下路缩短，圆心沿 −45° 朝叶冠排列；每条线从两次折弯改为一次，线宽 22 → 16，空心环外径 76 → 64、内径保持 32。双环净空 15 → 约 32.17；主体、三叶与尾部参数保持 V8。

本机 Chrome 检查 32 / 64 / 128 px；额外将外轮廓临时加粗 50% 做局部压力检查，64 / 128 px 仍可区分双线双环，32 px 仅用于轮廓识别。压力图保存在 `output/playwright/brand-v9-outline-stress.png`，未改动正式候选母版。

## 第八版方向

按所有者批准的几何重绘方案，使用原生 SVG 描述身体圆弧、三片叶冠和相切贝塞尔尾巴。连续的身体边界消除叶根开路径圆头，双电路线宽、转角和空心圆尺寸统一；电路起点裁于身体内部。保留浅—深—浅三叶与双须，采用纯色，无渐变。

母版画布 1000 × 1000；导出图形约 713 × 722，宽高比 0.9875。构造图直接复用生成参数，尾部通过 G1 切线检查，不声称全图 G2 连续。当前是待评审的 SVG 候选；新 PNG 仅由新母版渲染，未转换历史素材。

## 第七版方向

围绕所有者明确指定的基准精修，保留三片叶子两侧浅绿、中间深绿及两条须；以规整折角强化电路感，两个末端均为空心圆。图形约 1027 × 1041，宽高比 0.9866，画布 1254 × 1254；透明外背景，白色根部填充。参考 IBM 与微软官方规范中的光学线重、净空和尺寸方法，来源链接见 `v7/prompt.md`；未引入这些公司的图形素材。

## 第六版方向

所有者明确回到 V2 重新设计。保留白萝卜、右上三叶和左下根尖，收细墨绿轮廓、统一叶色，以一个空心电路触点替代双线路。图形约 941 × 937，宽高比 1.0043；透明画布 1254 × 1254，根部内部保留白色。当前仍为 PNG 候选，未矢量定稿。

## 第五版方向

根据“像医院 Logo、缺少科技感、整体需要 1:1 方形”的反馈，采用斜向宽萝卜、三片几何短叶、墨蓝与电光青配色；阶梯状留白和切角表达数据通路。画布为 1254 × 1254；只读测量的有色图形外接尺寸约 794 × 813，宽高比 0.9766，接近方形但并非精确等宽高。未拉伸、裁切或重采样原图。

V5 为白底 PNG 造型候选，在对比页固定白底展示；尚未制作透明或矢量母版。

## 第四版方向

所有者否定第三稿的黑色实心效果，补充网络萝卜与蓝绿流线两张参考。V4 采用深蓝 / 青绿开放曲线形成中空萝卜，两叶和向下根尖提供植物识别，内部仅保留一条信号线和一个节点。简约通过元素数量与留白实现，科技特征保留在结构内。参考图名称不改变 Radish Intelligence / RI。

对比页以 V4 白底原图作为主要造型依据；历史稿仍可切换底色。透明衍生图单独保存，边缘杂色未完全修复，当前不作为最终生产资产。

## 第三版方向

根据“更像头像 / 图片，缺少 Logo 简约感”的反馈，取消粗描边、多色、根纹电路和内部装饰，用单色实心萝卜剪影与叶冠留白组织识别。保留原形象的右上叶冠、左下根尖和整体斜向姿态。仍为 PNG 探索稿，尚未做精确矢量定稿。

## 第二版方向

以原有的圆润白萝卜、右上三片叶子、左下根尖与斜向姿态建立识别，将原有根纹简化为两道带端点的电路细节。参考图中的 LUOBO 不进入已确认品牌名称。第二版仍为 PNG 设计候选，未作为官网 Logo、favicon 或 GitHub 头像替换。

本目录为非公开部署的候选素材归档；当前 Vite 构建不引用本目录。用户已授权在项目中保留提供的参考图与版本备份，公开使用另按素材治理执行。
